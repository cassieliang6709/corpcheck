Technical route

From SEC source to auditable evidence

CorpCheck is not a prompt layer. It is a reproducible retrieval path whose decisions can be traced back to source code, database fields, and offline evaluation.

  1. 01

    Ingest

    Download and identify SEC filings

    Fetch 10-K and 10-Q filings from EDGAR while retaining ticker, CIK, accession number, filing date, and fiscal year.

  2. 02

    Represent

    Rebuild sections and tables

    Clean HTML without discarding sections, tables, or provenance; target 420 tokens / 60 overlap for SEC narrative and 320 tokens / 3-row overlap for tables.

  3. 03

    Encode + index

    Keep vector and full-text indexes

    all-MiniLM-L6-v2 produces normalized 384-dimensional embeddings; PostgreSQL stores both pgvector cosine and ts_rank.

  4. 04

    Retrieve

    Understand the query, then fuse candidates

    Parse issuer, filing type, and fiscal year; retrieve dense and sparse candidates, fuse with RRF, then remove sections superseded by amendments.

  5. 05

    Gate

    Refuse using raw cosine evidence

    Top-1 must be ≥ 0.42 and mean top-3 ≥ 0.40. The gate reads unboosted similarity so a ranking score cannot masquerade as confidence.

  6. 06

    Serve + evaluate

    HTTP, MCP, and evaluation share retrieve()

    The web app, agents, and FinanceBench harness do not carry separate retrieval logic. Generation is eligible only after the evidence gate passes.

DESIGN CONSTRAINT

Every answer must be explainable through input → candidates → fusion → revision governance → gate → source. Otherwise it is not audit-grade.

Why this is not generic RAG

Three promises that can be tested

01

Evaluation constrains retrieval

The serving API and FinanceBench evaluation call the same retrieve(). Strict Recall@10 is currently 0.1429, so generation remains closed instead of being marketed as reliable.

02

Every result is traceable

The web result retains ticker, filing type, fiscal year, filed date, and a direct SEC link; MCP filing context also returns the accession number.

03

Refusal happens before the LLM

Top-1 cosine must reach 0.42 and mean top-3 must reach 0.40. Missing either floor prevents weak evidence from reaching a generator.
