为什么不是普通 RAG

三个可以被验证的产品承诺

01

用评测约束检索

线上 API 与离线 FinanceBench 评测共用同一个 retrieve()。当前 strict Recall@10 基线只有 0.1429，因此生成能力继续关闭，而不是把低质量结果包装成产品准确率。

02

每条证据可追溯

网页结果保留 ticker、10-K/10-Q、财年、提交日期与 SEC 原始链接；MCP 的 filing context 还会返回 accession number。

03

拒答发生在 LLM 之前

top-1 cosine 需达到 0.42，mean top-3 需达到 0.40。任何一个门槛未通过，都不会把弱证据交给生成模型。

Verified now

  • 确定性 answerability gate
  • 1,662 filings / 469,874 chunks 的当前快照
  • HTTP API 与 MCP 共用检索路径
